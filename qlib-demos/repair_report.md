## 变更

- Python 3.12 本地虚拟环境、直接依赖清单和完整依赖锁；所有入口统一选择解释器并尊重调用方日期/provider配置。
- AST 白名单限制候选表达式，禁止未来引用和任意 Python 调用；交易日标签截断默认应用于所有评估截止日。
- 训练/验证/测试边界按标签跨度清除跨段样本；默认原生回测持仓2只、每次替换1只。
- 过滤非有限数据，正IC比例按有效日期计算；缺失指标保留null，并明确自相关和并列分组限制。
- 批量按相同有效样本排名，选择与最终测试分开；不足候选/测试样本时明确partial，不再误报成功。
- 单因子/批量输出完整输入、日期、标的、代码/数据指纹和实际运行依赖；provider缓存不影响数据指纹。
- Recorder默认使用项目内绝对本地路径（本地file URI会被规范化），可显式覆盖；保留原有未跟踪测试及运行数据，本地产物加入忽略规则。
