# 05 Browser MCP Agent 学习说明

## 这个例子学什么

学习浏览器自动化类 MCP：Agent 通过 Playwright MCP 控制网页、点击、截图、抽取内容。

## 先看哪些文件

- `main.py`：Streamlit 入口。
- `mcp_agent.config.yaml`：MCP server 和模型配置。
- `mcp_agent.secrets.yaml.example`：密钥模板。

## MCP 重点

- Server：`@playwright/mcp@latest`。
- Transport：由 `mcp-agent` 管理。
- Tools：打开网页、点击、输入、截图、读取页面内容。

## DeepSeek 配置

`mcp_agent.config.yaml` 已默认改成：

```yaml
openai:
  base_url: "https://api.deepseek.com/v1"
  default_model: "deepseek-chat"
```

再创建 `mcp_agent.secrets.yaml`：

```yaml
openai:
  api_key: "your-deepseek-api-key"
```

## 金融改造方向

自动打开财经网站、公告页面、交易所页面，抽取公开信息并生成结构化摘要。
