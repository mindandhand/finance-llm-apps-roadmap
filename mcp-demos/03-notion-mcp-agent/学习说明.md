# 03 Notion MCP Agent 学习说明

## 这个例子学什么

学习终端 Agent 如何连接 SaaS 类 MCP Server，并把对话记忆保存到 SQLite。

## 先看哪些文件

- `notion_mcp_agent.py`：核心入口。
- `requirements.txt`：依赖 Agno、MCP、SQLite memory。
- `README.md`：原始英文教程。

## MCP 重点

- Transport：stdio。
- Server：`npx -y @notionhq/notion-mcp-server`。
- Env：`NOTION_API_KEY`。
- Tools：读取、搜索、更新 Notion 页面。

## DeepSeek 配置

```bash
export DEEPSEEK_API_KEY=your-key
export OPENAI_BASE_URL=https://api.deepseek.com/v1
export OPENAI_MODEL=deepseek-chat
python notion_mcp_agent.py your_notion_page_id
```
