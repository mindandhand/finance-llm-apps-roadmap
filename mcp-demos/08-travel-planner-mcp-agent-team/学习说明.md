# 08 Travel Planner MCP Agent Team 学习说明

## 这个例子学什么

学习多 MCP 业务流：Airbnb MCP、Google Maps MCP、Google Search 工具一起完成一个复杂任务。

## 先看哪些文件

- `app.py`：Streamlit UI、MCP 初始化、Agent prompt、日历导出。
- `requirements.txt`：Agno、Streamlit、icalendar、搜索工具。

## MCP 重点

- MultiMCPTools 连接多个 server。
- 外部 API key 注入。
- 失败降级：MCP 不可用时仍生成普通建议。

## DeepSeek 配置

页面侧边栏输入 LLM API Key，或使用：

```bash
export DEEPSEEK_API_KEY=your-key
export OPENAI_BASE_URL=https://api.deepseek.com/v1
export OPENAI_MODEL=deepseek-chat
streamlit run app.py
```

## 金融改造方向

把旅行规划改成投资研究计划：输入股票/行业、时间周期、预算约束，输出调研任务、数据源、日程和成本。
