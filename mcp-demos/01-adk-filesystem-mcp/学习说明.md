# 01 ADK Filesystem MCP 学习说明

## 这个例子学什么

学习最基础的 MCP 形态：Agent 通过 stdio 启动一个本地 MCP Server，然后调用文件系统工具。

## 先看哪些文件

- `agent.py`：核心入口，创建 `MCPToolset` 并连接 `@modelcontextprotocol/server-filesystem`。
- `README.md`：原始英文教程。

## MCP 重点

- Transport：stdio。
- Server：`npx -y @modelcontextprotocol/server-filesystem`。
- Tools：列目录、读文件、写文件、建目录。

## 中国模型改造

这个示例使用 Google ADK，默认模型是 Gemini。要改成 DeepSeek/Qwen，需要先确认 ADK 当前版本是否支持 OpenAI-compatible 模型适配。建议先保留原例子跑通 MCP，再单独做模型层替换。

## 金融改造方向

把授权目录换成一个本地投研数据目录，例如 `data/`，让 Agent 读取 CSV、Markdown 研报、回测结果，并写出分析摘要。
