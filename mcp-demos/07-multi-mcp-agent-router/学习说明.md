# 07 Multi MCP Agent Router 学习说明

## 这个例子学什么

学习 Router 模式：先判断用户意图，再把任务交给不同专业 Agent，每个 Agent 只拿自己需要的 MCP 工具。

## 先看哪些文件

- `agent_forge.py`：Router、Agent 定义、MCP 连接、Streamlit UI。
- `requirements.txt`：Anthropic SDK、MCP、Streamlit。

## MCP 重点

- 多 Agent 权限隔离。
- 不同 Agent 绑定不同 MCP server。
- Router 决定任务流向。

## 中国模型改造

当前代码使用 Anthropic SDK 和 Claude tool-use 格式。要改 DeepSeek，需要把 Anthropic Messages API 调用替换成 OpenAI-compatible chat completions，并转换 tool schema。建议作为第二阶段重构，不在第一阶段硬改。

## 金融改造方向

把 Agent 改成：因子研究员、风控审查员、研报整理员、数据质量检查员。
