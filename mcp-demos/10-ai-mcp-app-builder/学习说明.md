# 10 AI MCP App Builder 学习说明

## 这个例子学什么

学习最高阶模式：用户描述一个 MCP App，Agent 在沙箱中生成代码、启动 MCP server，并把生成的 UI 接回聊天界面。

## 先看哪些文件

- `apps/web/app/api/mastra-agent/route.ts`：Agent、工具、OpenAI-compatible 模型配置。
- `apps/mcp-use-server/`：可生成/运行的 MCP server 模板。
- `apps/threejs-server/`：本地示例 MCP App。

## MCP 重点

- MCP server 生成。
- 动态 tools/resources/prompts。
- 沙箱运行与重启。
- 前端预览和工具刷新。

## DeepSeek 配置

`.env.example` 已改成 DeepSeek 默认：

```bash
OPENAI_API_KEY=your-deepseek-api-key
OPENAI_BASE_URL=https://api.deepseek.com/v1
OPENAI_MODEL=deepseek-chat
```
