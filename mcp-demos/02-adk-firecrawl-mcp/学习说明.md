# 02 ADK Firecrawl MCP 学习说明

## 这个例子学什么

在基础 MCP 连接上加入外部 API：Agent 通过 Firecrawl MCP 抓取网页、提取结构化内容。

## 先看哪些文件

- `agent.py`：核心入口，连接 `firecrawl-mcp`。
- `README.md`：原始英文教程。

## MCP 重点

- Transport：stdio。
- Server：`npx -y firecrawl-mcp`。
- Env：`FIRECRAWL_API_KEY`。
- Tools：网页抓取、站点爬取、内容抽取。

## 中国模型改造

同 `01`，这个例子基于 Google ADK。先学习 MCP 工具接入，再替换模型层。

## 金融改造方向

抓取上市公司官网、公告页面、券商研报目录、财经新闻页面，然后让 Agent 输出结构化投研摘要。
