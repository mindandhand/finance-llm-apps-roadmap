# 06 Multi MCP Agent 学习说明

## 这个例子学什么

学习一个 Agent 同时连接多个 MCP Server，并把工具组合成跨平台工作流。

## 先看哪些文件

- `multi_mcp_agent.py`：核心入口。
- `requirements.txt`：Agno、MCP、dotenv。

## MCP 重点

- Server：GitHub、Perplexity、Calendar、Gmail。
- 工具组合：搜索、代码仓库、日历、邮件。
- 记忆：SQLite 保存 session。

## DeepSeek 配置

```bash
export DEEPSEEK_API_KEY=your-key
export OPENAI_BASE_URL=https://api.deepseek.com/v1
export OPENAI_MODEL=deepseek-chat
python multi_mcp_agent.py
```
