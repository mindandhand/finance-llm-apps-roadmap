# 09 MCP Apps Generative UI Showcase 学习说明

## 这个例子学什么

学习 MCP Apps：MCP Server 不只暴露工具，还暴露可渲染的 HTML UI resource，让聊天界面内出现交互式应用。

## 先看哪些文件

- `mcp-server/server.ts`：注册 tools 和 UI resources。
- `mcp-server/src/stocks.ts`：投资组合模拟逻辑。
- `mcp-server/apps/trading-app.html`：投资 UI。
- `src/app/api/copilotkit/[[...slug]]/route.ts`：CopilotKit + MCP Apps middleware。

## MCP 重点

- Tools：例如 `create-portfolio`、`execute-trade`。
- Resources：例如 `ui://stocks/trading-app.html`。
- `_meta["ui/resourceUri"]`：把工具调用结果和 UI resource 关联起来。

## DeepSeek 配置

API route 已改成优先读取：

```bash
OPENAI_API_KEY=your-deepseek-key
OPENAI_MODEL=deepseek-chat
```

如果运行时框架需要自定义 OpenAI base URL，还需要继续在 CopilotKit runtime 层补 `OPENAI_BASE_URL` 支持。
