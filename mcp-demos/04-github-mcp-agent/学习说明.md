# 04 GitHub MCP Agent 学习说明

## 这个例子学什么

学习 Streamlit UI 如何驱动 Agent，并通过 Docker 启动官方 GitHub MCP Server。

## 先看哪些文件

- `github_agent.py`：Streamlit 页面和 MCP 调用逻辑。
- `requirements.txt`：Agno、Streamlit、MCP 依赖。
- `README.md`：原始英文教程。

## MCP 重点

- Transport：Docker stdio。
- Server：`ghcr.io/github/github-mcp-server`。
- Env：`GITHUB_TOKEN` / `GITHUB_PERSONAL_ACCESS_TOKEN`。
- Toolsets：`repos,issues,pull_requests`。

## DeepSeek 配置

页面侧边栏输入 DeepSeek key，或使用环境变量：

```bash
export DEEPSEEK_API_KEY=your-key
export OPENAI_BASE_URL=https://api.deepseek.com/v1
export OPENAI_MODEL=deepseek-chat
streamlit run github_agent.py
```

## 金融改造方向

分析量化策略仓库活跃度、issue 质量、PR 合并节奏，辅助选择开源金融工具。
